This directory manages the component list, pricing, and purchase documentation for the Analog PID Wall-Following Robot.

All component specs, sourcing links, component costs, and inventory tracking are maintained in our live Google Sheet:

## 📑 Purchase Receipts & Proofs

Please upload all purchase receipts, invoices, and payment confirmation PDFs/images directly into this folder (or a `/receipts` subfolder) for auditing.

* **Allowed Formats:** `.pdf`, `.png`, `.jpg`
* **Naming Convention:** `YYYY-MM-DD_Vendor_Description` (e.g., `2026-08-15_JLCPCB_PCB-Fabrication.pdf`)
