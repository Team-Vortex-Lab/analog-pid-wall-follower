# 📑 Purchase Receipts & Invoices

This folder contains payment proofs, invoices, and order receipts for auditing and budget tracking.

* **Allowed Formats:** `.pdf`, `.png`, `.jpg`
* **File Naming Convention:** `YYYY-MM-DD_Vendor_Description`
  *(e.g., `2026-08-15_JLCPCB_PCB-Fabrication.pdf`)*

> **Reminder:** Ensure the total amount spent is also logged in the [Master BOM Google Sheet](https://docs.google.com/spreadsheets/d/1535ly-6GC8yO2m3U3nibKsXknjWyNcsG9HDwD5iCAMU/edit?usp=sharing).
