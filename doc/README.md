# 📚 Project Documentation & Datasheets

This directory contains technical documentation, system block diagrams, user guides, and component datasheets for the Analog PID Wall-Following Robot.

---

## 📁 Folder Contents

* **System Architecture:** High-level block diagrams and signal flow documentation.
* **Datasheets:** Key component specification sheets (Op-Amps, sensors, power regulators).
* **Tuning Guides:** Manual calibration procedures for potentiometer feedback loops.
* **Reports:** Technical write-ups and team milestone reports.

> **Note:** For specific CAD models, Altium schematics, or LTspice simulations, please refer to their respective root directories (`/cad`, `/schematics`, `/simulation`).
