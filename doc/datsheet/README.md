# 📑 Component Datasheets

This directory contains PDF specifications and pinout references for key hardware components used in the Analog PID Wall-Following Robot.

* **Contents:** Technical datasheets for Op-Amps, distance sensors, power regulators, and MOSFET drivers.
* **Naming Standard:** Use `PartNumber_Description.pdf` *(e.g., `LM358_OpAmp.pdf`, `GP2Y0A51SK0F_IR_Sensor.pdf`)*.

> **Note:** Only official manufacturer datasheets should be uploaded here for quick offline team reference.
