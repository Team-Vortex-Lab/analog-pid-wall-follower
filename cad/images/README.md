# CAD Image Previews

This folder contains rendered previews and screenshots of the 3D chassis components and assemblies for quick visual inspection on GitHub.

* **Format:** Preferred formats are `.png` or `.jpg`.
* **Usage:** Images in this directory are linked directly into `cad/README.md` for fast review without opening SolidWorks.

> **Tip:** Keep image file sizes small (< 2 MB each) to ensure fast rendering in GitHub's web interface.
