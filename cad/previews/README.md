# 🖼️ 3D Model Image Previews

Visual previews (`.png` / `.jpg`) for quick CAD inspection directly on GitHub without launching SolidWorks.

---

## 📌 Guidelines for Contributors

* **Naming:** Match preview filenames to their CAD sources (e.g., `chassis_base.SLDPRT` $\rightarrow$ `chassis_base_preview.png`).
* **Format:** Use isometric views on a light background ($1920 \times 1080\text{ px}$ recommended).
* **Update Rule:** Replace the preview whenever the corresponding SolidWorks file is updated.
